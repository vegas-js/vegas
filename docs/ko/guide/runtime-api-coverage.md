# Runtime API coverage

Runtime API coverage는 `scripts/runtime-api-status.json`과 Runtime 구현에서 자동 생성되는 reference입니다.

현재 이 생성 페이지의 source of truth는 영어 문서에만 둡니다. 최신 구조적 coverage, behavior category, audit 및 contract test 집계는 [영어 Runtime API coverage](/guide/runtime-api-coverage/)를 참고하세요.

이 한국어 route는 언어를 전환할 때 같은 페이지 위치를 유지하기 위해 제공합니다. coverage의 의미와 읽는 방법은 [Local Runtime](./local-runtime#api-coverage-읽기)에서도 설명합니다.
