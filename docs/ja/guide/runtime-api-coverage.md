# Runtime API coverage

Runtime API coverage は `scripts/runtime-api-status.json` と Runtime 実装から自動生成されるリファレンスです。

現在、この生成ページのsource of truthは英語版だけに置いています。最新の構造上のcoverage、挙動カテゴリ、監査・contract testの集計については [英語版 Runtime API coverage](/guide/runtime-api-coverage/) を参照してください。

この日本語routeは、言語を切り替えたときに同じページ位置を維持するために用意しています。coverageの意味と読み方については [Local Runtime](./local-runtime#api-coverage-の読み方) でも説明しています。
